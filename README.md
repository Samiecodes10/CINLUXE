# CINLUXE
CINLUXE is a menu-driven Movie Ticket Booking System developed using the C programming language.It is designed to provide users with a simple and convenient way to book movie tickets through a computer-based application.The system allows users to explore available movies,check seat availability,select their preferred seats,and confirm their bookings.

# Main Features
- Movie Listing: Displays available movies along with their ticket prices.
- Seat Availability: Shows a seating layout where 'O' represents available seats and 'X' represents booked seats.
- Movie Selection: Allows users to choose their preferred movie.
- Ticket Booking: Accepts customer details and the number of tickets required.
- Seat Selection: Allows users to select specific seats according to availability.
- Booking Validation: Checks whether the selected seats are valid and not already booked.
- Booking Confirmation: Generates a booking ID and displays the complete booking details.
- Bill Generation: Calculates and displays the total ticket amount.
- User-Friendly Messages: Provides greetings, booking confirmations, error messages and thank-you messages.

# Working of the Project
1. When the program starts, it displays a welcome message and the main menu.
2. Users can view the available movies and their ticket prices.
3. To book tickets, users select a movie and enter their name.
4. The system asks for the number of tickets required.
5. A seat layout is displayed, showing available and booked seats.
6. Users select their preferred seats.
7. The program validates each selection and prevents duplicate bookings.
8. After successful selection, the system generates a booking ID and calculates the total amount.
9. Finally, a booking confirmation is displayed with all the relevant details.

# Technologies and C Concepts Used
The project is developed using C programming language and implements the following concepts:
- Structures (struct) – To store movie information.
- Arrays – To manage movie and booking information.
- Two-Dimensional Arrays – To represent the seating arrangement.
- Strings – To store movie and customer names.
- Functions – To divide the program into smaller modules.
- Loops – To repeat menu options and seat selection.
- Conditional Statements – To validate bookings and seat availability.
- Switch-Case – To manage different menu operations.
